# Menu-Bar Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A macOS menu-bar app shows the live registry and opens the existing board, without reading or writing the registry files.

**Architecture:** A Tauri 2 app in `desktop/` is a second client of the loopback daemon. Rust fetches `GET /api/health` and `GET /api/live`, starts the daemon only when the connection is refused, and pushes rows to a small webview. The board window loads `http://127.0.0.1:<port>/` from the daemon. The app has its own login item. Quitting it does not stop the daemon.

**Tech Stack:** Tauri 2 (`tauri` with the `tray-icon` feature), Rust 2021, a plain HTML panel. No Node UI framework. No new Python dependencies.

**Slice:** 2 of 2. Slice 1 is on `main` at `c6905b5`. Do not change who opens `registry.json`. Do not add Archive, Kill, or Send to the panel.

**Living spec:** After the panel renders rows, write `docs/specs/menu-bar.md` from the code and add its row to `docs/specs/README.md`. Do not edit `docs/superpowers/specs/2026-11-16-registry-daemon-design.md`.

```rust
                .decorations(false)
                .always_on_top(true)
```

```rust
use serde::Deserialize;
use serde::Serialize;
use serde_json::Value;

#[derive(Debug, Serialize, PartialEq)]
pub struct Glance {
    pub attention_count: usize,
    pub rows: Vec<GlanceRow>,
}

#[derive(Debug, Serialize, PartialEq)]
pub struct GlanceRow {
    pub session_id: String,
    pub depth: u8,
    pub children: Vec<String>,
    pub parent_session_id: Option<String>,
    pub mark: String,
    pub agent_type: String,
    pub name: String,
    pub title: String,
    pub status: String,
    pub project: String,
    pub summary: String,
    pub directory: String,
    pub token_total: Option<i64>,
    pub cpu_percent: Option<f64>,
    pub memory_bytes: Option<i64>,
    pub age_seconds: Option<i64>,
}

#[derive(Deserialize)]
struct Live {
    active: Vec<Value>,
    attention: Vec<Value>,
    #[serde(default)]
    corrupt: bool,
}

pub fn glance_from_live(body: &str) -> Result<Glance, String> {
    let live: Live = serde_json::from_str(body).map_err(|e| e.to_string())?;
    if live.corrupt {
        return Err("registry is corrupt".into());
    }
    let mut flat = Vec::new();
    for value in live.attention.iter().chain(live.active.iter()) {
        flat.push(row_from(value)?);
    }
    let ids: Vec<String> = flat.iter().map(|r| r.session_id.clone()).collect();
    for row in &mut flat {
        if row.parent_session_id.as_ref().is_some_and(|id| ids.contains(id)) {
            row.depth = 1;
        }
    }
    for row in &mut flat {
        row.children = flat
            .iter()
            .filter(|other| other.parent_session_id.as_deref() == Some(row.session_id.as_str()))
            .map(|other| other.session_id.clone())
            .collect();
    }
    let attention_count = live.attention.len();
    Ok(Glance { attention_count, rows: flat })
}

fn row_from(value: &Value) -> Result<GlanceRow, String> {
    let session_id = text(value, "session_id");
    if session_id.is_empty() {
        return Err("session missing session_id".into());
    }
    let agent_type = text(value, "agent_type");
    Ok(GlanceRow {
        session_id,
        depth: 0,
        children: Vec::new(),
        parent_session_id: value.get("parent_session_id").and_then(|v| v.as_str()).map(str::to_string).filter(|s| !s.is_empty()),
        mark: mark(&agent_type),
        name: first_nonempty(&[text(value, "peer_name"), text(value, "title"), text(value, "session_id")]),
        title: text(value, "title"),
        status: text(value, "status"),
        project: text(value, "project"),
        summary: text(value, "summary"),
        directory: text(value, "directory"),
        token_total: token_total(&agent_type, value.get("tokens")),
        cpu_percent: value.get("cpu_percent").and_then(|v| v.as_f64()),
        memory_bytes: value.get("memory_bytes").and_then(|v| v.as_i64()),
        age_seconds: age_seconds(value.get("last_ping")),
        agent_type,
    })
}

fn mark(agent_type: &str) -> String {
    match agent_type {
        "claude" => "C",
        "codex" => "X",
        "cursor" => ">",
        other => other.chars().next().unwrap_or('?').to_string(),
    }.into()
}

fn token_total(agent_type: &str, tokens: Option<&Value>) -> Option<i64> {
    let tokens = tokens?.as_object()?;
    match agent_type {
        "claude" => Some(int(tokens.get("input_tokens")) + int(tokens.get("output_tokens"))),
        "codex" => Some(int(tokens.get("total_tokens"))),
        _ => None,
    }
}

fn int(value: Option<&Value>) -> i64 {
    value.and_then(|v| v.as_i64()).unwrap_or(0)
}

fn text(value: &Value, key: &str) -> String {
    value.get(key).and_then(|v| v.as_str()).unwrap_or("").to_string()
}

fn first_nonempty(parts: &[String]) -> String {
    parts.iter().find(|s| !s.is_empty()).cloned().unwrap_or_default()
}

fn age_seconds(value: Option<&Value>) -> Option<i64> {
    let text = value?.as_str()?;
    let parsed = chrono::DateTime::parse_from_rfc3339(text).ok()?;
    let seconds = (chrono::Utc::now() - parsed.with_timezone(&chrono::Utc)).num_seconds();
    Some(seconds.max(0))
}
```

- [ ] **Step 3: Implement the client**

`classify_health` opens `127.0.0.1` with `std::net::TcpStream`, writes `GET /api/health HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n`, and reads the response. Set read and write timeouts to 1 second. Do not use a crate that honors `HTTP_PROXY`.

```rust
#[derive(Debug, PartialEq, Eq)]
pub enum Health { Ours, Stranger, Refused }

pub fn classify_health(port: u16) -> Health {
    use std::io::{Read, Write};
    use std::net::{TcpStream, SocketAddr};
    use std::time::Duration;
    let addr = SocketAddr::from(([127, 0, 0, 1], port));
    let mut stream = match TcpStream::connect_timeout(&addr, Duration::from_secs(1)) {
        Ok(stream) => stream,
        Err(_) => return Health::Refused,
    };
    let _ = stream.set_read_timeout(Some(Duration::from_secs(1)));
    let _ = stream.set_write_timeout(Some(Duration::from_secs(1)));
    if stream.write_all(b"GET /api/health HTTP/1.1\r\nHost: 127.0.0.1\r\nConnection: close\r\n\r\n").is_err() {
        return Health::Stranger;
    }
    let mut buf = String::new();
    if stream.read_to_string(&mut buf).is_err() {
        return Health::Stranger;
    }
    if buf.contains("\"service\":\"agent-registry\"") || buf.contains("\"service\": \"agent-registry\"") {
        Health::Ours
    } else {
        Health::Stranger
    }
}
```

`ensure_daemon(port_hint: Option<u16>) -> Result<u16, String>`:

1. Registry directory is the parent of `AGENT_REGISTRY_PATH` when that variable is set, otherwise `dirs` is not a dependency: use `std::env::home_dir` via `std::env::var("HOME")` joined with `.local/share/agent-registry`.
2. If `daemon.pid` contains an integer and `kill(pid, 0)` succeeds, the port is the integer in `daemon.port`. A `port_hint` or `AGENT_REGISTRY_DAEMON_PORT` that differs returns `Err(format!("daemon already listening on {live}"))`.
3. Otherwise the port is `port_hint`, then `AGENT_REGISTRY_DAEMON_PORT`, then `8765`.
4. `Health::Ours` returns the port.
5. `Health::Stranger` returns `Err("port is not agent-registry")` and does not spawn.
6. `Health::Refused` spawns `agent-registry` with args `["daemon", "run", "--port", port]`, `stdin` null, stdout and stderr appended to `daemon.log` in the registry directory. Poll `classify_health` every 100ms until `AGENT_REGISTRY_DAEMON_START_TIMEOUT` seconds (default 5). Success returns the port. Timeout returns `Err("daemon did not become healthy")`.

`live(port) -> Result<String, String>` sends `GET /api/live` the same way and returns the body after the header blank line.

The spawn function takes the program name so a test can pass a fake. The default program is `agent-registry` from `PATH`. Do not spawn `python` and do not open `registry.json`.

```html
    return `<div class="row${row.depth ? " child" : ""}">` +
      `<span class="mark engine-${esc(row.agent_type)}">${esc(row.mark)}</span>` +
      `<strong>${esc(row.name)}</strong> ${esc(row.status)}` +
      `<div>${esc(row.title)}</div>` +
      `<div>${esc(row.project)} ${esc(row.summary)}</div>` +
      `<div>${esc(row.directory)}</div>` +
      (row.parent_session_id && row.depth === 0 ? `<div>parent ${esc(row.parent_session_id)}</div>` : "") +
      (usage ? `<div>${esc(usage)}</div>` : "") +
      kids +
      `</div>`;
  }
  rows.innerHTML = glance.rows.filter((row) => row.depth === 0).map(rowHtml).join("");
}
window.__agentRegistry = {
  render,
  fail(message) {
    error.textContent = message;
    error.classList.remove("hidden");
    rows.innerHTML = "";
    attention.classList.add("hidden");
  }
};
document.getElementById("open-board").addEventListener("click", () => {
  window.__TAURI_INTERNALS__.invoke("open_board");
});
</script>
</body>
</html>
```

The only control is Open board. There is no Archive, Kill, Send, or prune button.
